<h2 align="center" style="font-size: 2rem; color: #0984e3; border-bottom: 2px solid #0984e3; padding-bottom: 10px; margin-top: 40px;">Contribution Guidelines🏗</h2>

<div style="background-color: #fff8e1; padding: 20px; border-radius: 10px; margin: 20px 0; border-left: 5px solid #ffc107;">
  <p style="font-size: 1.1rem; line-height: 1.6; color: #2d3436; margin-bottom: 20px;">
    Are we missing any of your favorite features, which you think you can add to it❓ We invite you to contribute to this project and make it better. 
    To start contributing, follow the below guidelines: 
  </p>
</div>

<ol style="background-color: #f5f5f5; padding: 20px 40px; border-radius: 10px; margin: 20px 0; list-style-position: inside;">
  <li style="padding: 10px 0; color: #2d3436;">Fork this repository.</li>
  <li style="padding: 10px 0; color: #2d3436;">Clone your forked copy of the project.
    <div style="background-color: #263238; color: #f5f5f5; padding: 10px; border-radius: 5px; margin: 10px 0; font-family: monospace; overflow-x: auto;">
      git clone https://github.com/&lt;your_user_name&gt;/Portfolio-Collection.git
    </div>
  </li>
  <li style="padding: 10px 0; color: #2d3436;">Navigate to the project directory 📁.
    <div style="background-color: #263238; color: #f5f5f5; padding: 10px; border-radius: 5px; margin: 10px 0; font-family: monospace; overflow-x: auto;">
      cd Portfolio-Collection
    </div>
  </li>
  <li style="padding: 10px 0; color: #2d3436;">Add a reference(remote) to the original repository.
    <div style="background-color: #263238; color: #f5f5f5; padding: 10px; border-radius: 5px; margin: 10px 0; font-family: monospace; overflow-x: auto;">
      git remote add upstream https://github.com/avinash201199/Portfolio-Collection.git
    </div>
  </li>
  <li style="padding: 10px 0; color: #2d3436;">Check the remotes for this repository.
    <div style="background-color: #263238; color: #f5f5f5; padding: 10px; border-radius: 5px; margin: 10px 0; font-family: monospace; overflow-x: auto;">
      git remote -v
    </div>
  </li>
  <li style="padding: 10px 0; color: #2d3436;">Always take a pull from the upstream repository to your master branch to keep it at par with the main project(updated repository).
    <div style="background-color: #263238; color: #f5f5f5; padding: 10px; border-radius: 5px; margin: 10px 0; font-family: monospace; overflow-x: auto;">
      git pull upstream main
    </div>
  </li>
  <li style="padding: 10px 0; color: #2d3436;">Create a new branch.
    <div style="background-color: #263238; color: #f5f5f5; padding: 10px; border-radius: 5px; margin: 10px 0; font-family: monospace; overflow-x: auto;">
      git checkout -b &lt;your_branch_name&gt;
    </div>
  </li>
  <li style="padding: 10px 0; color: #2d3436;">Perform your desired changes to the code base.</li>
  <li style="padding: 10px 0; color: #2d3436;">Track your changes✔️.
    <div style="background-color: #263238; color: #f5f5f5; padding: 10px; border-radius: 5px; margin: 10px 0; font-family: monospace; overflow-x: auto;">
      git add .
    </div>
  </li>
  <li style="padding: 10px 0; color: #2d3436;">Commit your changes.
    <div style="background-color: #263238; color: #f5f5f5; padding: 10px; border-radius: 5px; margin: 10px 0; font-family: monospace; overflow-x: auto;">
      git commit -m "Relevant message"
    </div>
  </li>
  <li style="padding: 10px 0; color: #2d3436;">Push the committed changes in your feature branch to your remote repo.
    <div style="background-color: #263238; color: #f5f5f5; padding: 10px; border-radius: 5px; margin: 10px 0; font-family: monospace; overflow-x: auto;">
      git push -u origin &lt;your_branch_name&gt;
    </div>
  </li>
  <li style="padding: 10px 0; color: #2d3436;">To create a pull request, click on <code style="background-color: #e0e0e0; padding: 2px 5px; border-radius: 3px;">compare and pull requests</code>.</li>
  <li style="padding: 10px 0; color: #2d3436;">Add appropriate title and description to your pull request explaining your changes and efforts done.</li>
  <li style="padding: 10px 0; color: #2d3436;">Click on <code style="background-color: #e0e0e0; padding: 2px 5px; border-radius: 3px;">Create Pull Request</code>.</li>
  <li style="padding: 10px 0; color: #2d3436;">Voila❗ You have made a PR to the Portfolio-Collection 💥. Wait for your submission to be accepted and your PR to be merged.(Hacktoberfest 2023)</li>
</ol>
